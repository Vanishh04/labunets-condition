# Labunets Condition

Лендинг тренера стоек на руках Ивана Лабунца. Визуально близко к [dr-ozolin.com](https://dr-ozolin.com). Смысловой упор — гимнастическая **ОФП / ЗФП**, **СФП** и кондиции под стойку (логика базы как у Академии «Рассвет»), а не трюк без фундамента.

Языки: **RU / EN / UA** (українська — третя в перемикачі).

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx --yes serve .
```
